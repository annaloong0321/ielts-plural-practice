How to use:
1. Select a practice set (or add your own).
2. Load the matching audio file.
3. Play the audio — pause at each sentence.
4. Click each blank to mark: sg (singular) or pl (plural). Use ? if unsure.
5. Click Check Answers when done — missed items appear below with sentence context for re-listening.
